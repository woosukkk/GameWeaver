# Document tools

## PDF Inspector

- Source: [firecrawl/pdf-inspector](https://github.com/firecrawl/pdf-inspector)
- Status: 조건부 사용
- Form: Rust 라이브러리와 CLI, Node.js/Python/WebAssembly 바인딩
- Use for: PDF 분류, 로컬 텍스트 추출, Markdown 변환, OCR 필요 여부 판단

PDF 처리 요구사항이 있을 때만 해당 프로젝트의 언어와 실행 환경에 맞는 패키지를 추가합니다. 스캔 문서에는 별도의 OCR 경로가 필요합니다.
