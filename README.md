# Init Project Settings

새 프로젝트를 시작할 때 재사용하는 공통 설정과 템플릿입니다.

## Structure

- `common/`: 모든 프로젝트에 적용할 기본 파일
- `.github/`: GitHub 이슈, PR, 자동화 템플릿
- `skills/`: AI 에이전트용 재사용 스킬
- `tools/`: 선호 오픈소스와 사용 조건
- `templates/`: 기술 스택별 프로젝트 템플릿
- `scripts/`: 프로젝트 초기화 스크립트

Git 협업 규칙의 원본은 `common/CONTRIBUTING.md`이며, GitHub 템플릿은 해당 규칙에 맞춰 관리합니다.
